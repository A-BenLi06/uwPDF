## 新增与改进

- **自动适配深浅色主题**：阅读界面现在跟随 Windows 的应用主题，在浅色与深色外观之间自动切换。工具栏、搜索面板、缩略图侧栏、批注浮层及分隔线同步调整，夜间阅读时界面更加协调。
- **弹窗与交互颜色同步**：历史记录、OCR、分享、打印和隐私等对话框跟随当前主题；缩略图选中、悬停状态及画笔弹出面板也会同步更新，无需重新打开文档。
- **保持文档原有外观**：主题切换只调整应用界面，PDF 页面、墨迹预览的白色纸张及打印内容保持原色，阅读缩放和页面位置不因切换主题而重置。

## 问题修复

- **恢复原生标题栏配色**：标题栏和窗口按钮的颜色交由 Windows 管理，遵循系统标题栏强调色设置及窗口激活状态，修复此前强制覆盖标题栏颜色的问题。
- **修复窗口按钮背景异常**：移除不适用于原生标题栏的透明背景覆盖，解决标题栏按钮出现白色块等显示异常。
- **改善深色界面可读性**：修正浅色专用背景和文字颜色，使搜索、缩略图及弹窗在深色主题下更清晰。

## 下载与安装

- **推荐安装（完整包）**：下载对应架构的 `_Install.zip` 并解压，右键运行 `Add-AppDevPackage.ps1` 安装应用和依赖。首次安装若尚未信任证书，请先以管理员权限将随包的 `uwPDF.cer` 导入「本地计算机 → 受信任的人」，再以当前 Windows 用户运行安装脚本。
- **独立单包安装**：已在系统中信任证书并安装所需依赖的用户，可直接双击安装对应架构的 `.appx` 或 `.msix`。
- **系统要求**：x86 / x64 / ARM 支持 Windows 10 1607 及以上；ARM64 支持 Windows 10 1809 及以上。
- **版本说明**：本版本为 GitHub 侧载预览版（`Ben.LitePdfViewerPreview`），与 Microsoft Store 商店版相互独立，沿用此前侧载版的签名证书。

## 注意事项

- 浮动阅读控制栏保留深色外观；主题切换不会反转 PDF 页面或改变打印颜色。
- 本地草稿用于辅助恢复未保存批注；文档编辑完成后，仍建议点击工具栏「保存」将修改写入 PDF 文件。
- ARM 设备运行、实际高对比度切换及不同 Windows 个性化配置仍需实机验收。本次 GitHub 发布不代表 Microsoft Store 已更新。
