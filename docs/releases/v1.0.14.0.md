## 新增功能与改进

- **本地草稿恢复**：未保存的墨迹和高亮会写入独立的本地草稿。重新打开同一份未被外部修改的 PDF 时，应用会尝试恢复完整草稿，并保留为待保存编辑；点击保存才会写入原 PDF。
- **草稿状态提示**：工具栏显示草稿保存状态和存储错误，保存文件后会清理对应草稿。PDF 被其他应用修改时，原有本地批注和草稿会单独保留。
- **应用内隐私与支持入口**：更多菜单新增可离线阅读的隐私政策和支持链接，覆盖简体中文、繁體中文、English 与日本語。
- **打印修复**：改用适合 XAML 打印的位图路径，并在打印任务结束前保留页面图像和视觉树，修复打印空白页问题。
- **窗口关闭流程调整**：移除受限的 `confirmAppClose` 权限及关闭拦截，改为通过本地草稿保留未保存编辑。

## 下载与安装

- 推荐下载对应架构的 **`_Install.zip`** 并完整解压。首次安装时，将随包提供的公开证书 `uwPDF.cer` 导入「本地计算机 → 受信任的人」，然后以当前 Windows 用户运行 `Add-AppDevPackage.ps1`。
- 已信任证书并安装依赖的用户，也可直接使用对应的 `.appx` / `.msix`。
- x86 / x64 / ARM 需要 Windows 10 1607 或更新版本；ARM64 需要 Windows 10 1809 或更新版本。
- 此处提供的是侧载版 `Ben.LitePdfViewerPreview`，与 Microsoft Store 版独立。安装包沿用此前侧载版的自签名证书。

## 已知限制

- 草稿不是原 PDF 的自动保存。应用在草稿写入完成前被突然终止时，最近编辑仍可能丢失；重要编辑请显式保存。
- ARM / ARM64、旧版 Windows 和 Windows 10 Mobile 的实机运行，以及 Windows 10 开始菜单动态磁贴外观，仍需设备验收。
- 本次 GitHub 发布不代表 Microsoft Store 已通过审核或已更新。
