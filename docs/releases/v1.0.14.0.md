## 新增与改进

- **未保存批注自动恢复**：墨迹和高亮在编辑过程中会自动写入本地草稿。若遇应用意外关闭或直接退出，再次打开同一文档即可自动恢复未保存的内容，确认无误后点击「保存」写回 PDF，防止心血丢失。
- **草稿状态与冲突保护**：顶部工具栏新增草稿保存状态提示；若原文档在外部被其他软件修改，应用会自动归档隔离旧草稿，防止发生意外冲突与覆盖。
- **更平滑的退出体验**：移除了此前生硬的窗口关闭弹窗拦截；在后台草稿机制的保护下，即便直接退出也能保留编辑进度，下次启动无缝续读。
- **离线隐私声明与支持**：「更多」菜单新增离线隐私政策与技术支持页面，并完整适配中（简/繁）、英、日多语言。

## 问题修复

- **修复打印空白页问题**：彻底重构了打印页面的渲染流程，解决了此前打印或导出 PDF 时偶现整页空白的严重缺陷。

## 下载与安装

- **推荐安装（完整包）**：下载对应架构的 `_Install.zip` 并解压，右键运行 `Add-AppDevPackage.ps1`，按脚本提示即可一键安装证书与所有依赖。
- **独立单包安装**：已在系统中信任过证书的用户，可直接双击安装对应架构的 `.appx` 或 `.msix`。
- **系统要求**：x86 / x64 / ARM 支持 Windows 10 1607 及以上；ARM64 支持 Windows 10 1809 及以上。
- **版本说明**：本版本为 GitHub 侧载预览版（`Ben.LitePdfViewerPreview`），与 Microsoft Store 商店版相互独立。

## 注意事项

- 本地草稿主要用于异常退出的容灾防丢；文档编辑完成后，仍建议点击工具栏「保存」将修改永久固化到 PDF 文件。
